# Scala: рекурсивные функции

- `pascal` — элемент равен сумме двух элементов над ним, края треугольника равны 1.
- `balance` — внутренняя функция идёт по списку и считает открытые скобки; если закрывающих больше, чем открытых, баланс нарушен.
- `countChange` — число вариантов = варианты с первой монетой + варианты без неё.
- `nQueens` — ферзи ставятся по строкам с перебором с возвратом; если ни одна колонка не подходит, возвращается `None`.
- `boardToString` — строит доску строкой без изменяемых переменных и циклов (1 — ферзь, 0 — пустая клетка), `printBoard` только печатает её.

Пример: `nQueens(4)` = `[1,3,0,2]`, для 2 и 3 решения нет.
