## 2. Scala: misc

В этой лабораторной нужно было написать четыре функции с помощью рекурсии. Рекурсия — это когда функция вызывает саму себя, но с более простыми данными, пока не дойдёт до случая, ответ на который известен сразу.

Запуск:
```bash
scala run Main.scala
```

### 1. Треугольник Паскаля — `pascal(c, r)`

Функция возвращает число из треугольника Паскаля по номеру столбца `c` и строки `r` (нумерация с нуля).

Как работает: крайние числа в каждой строке равны 1. Любое другое число равно сумме двух чисел над ним. Поэтому функция вызывает саму себя для этих двух чисел из предыдущей строки, пока не дойдёт до края треугольника.

### 2. Баланс скобок — `balance(chars)`

Функция проверяет, правильно ли расставлены скобки в тексте: каждая `(` должна закрываться своей `)`.

Как работает: внутри есть вспомогательная функция `loop`, которая идёт по символам по одному и считает, сколько скобок сейчас открыто. На `(` счётчик увеличивается, на `)` уменьшается, остальные символы пропускаются. Если счётчик стал меньше нуля, значит, скобку закрыли раньше, чем открыли, и ответ `false`. Когда символы закончились, ответ `true`, только если счётчик равен нулю.

### 3. Размен денег — `countChange(money, coins)`

Функция считает, сколькими способами можно набрать сумму `money` из монет `coins`. Каждую монету можно брать сколько угодно раз.

Как работает: все способы делятся на две группы. В первой мы берём первую монету из списка, и остаётся разменять сумму поменьше. Во второй мы совсем не используем первую монету и размениваем ту же сумму остальными монетами. Ответ — сумма этих двух вариантов.

Когда рекурсия останавливается:
- сумма стала ровно 0 — нашли один способ;
- сумма стала меньше 0 или монеты закончились — способа нет.

### 4. Задача о ферзях — `nQueens(size)`

Нужно расставить на доске `size × size` столько же ферзей так, чтобы они не били друг друга. Результат — массив, где номер элемента это строка, а значение это столбец, в котором стоит ферзь. Если решения нет (например, для доски 2×2 или 3×3), функция возвращает `None`.

Как работает (перебор с возвратом):
1. Ставим ферзей по одному в каждую строку, начиная сверху.
2. В строке пробуем столбцы слева направо. Функция `isSafe` проверяет, что новый ферзь не стоит в одном столбце или на одной диагонали с уже поставленными.
3. Если место подходит, ставим ферзя и переходим к следующей строке.
4. Если в следующих строках расставить не получилось, возвращаемся назад и пробуем другой столбец.
5. Когда все ферзи расставлены, решение найдено.

Функция `printBoard` печатает доску: 1 — ферзь, 0 — пустая клетка.
