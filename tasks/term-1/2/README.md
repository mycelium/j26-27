# 2. Scala: misc (Рекурсия)

**Файлы:**
- `Main.scala` — исходный код с реализацией всех четырех функций.
- `README.md` — описание решения.

## Постановка задачи:
В данном задании необходимо реализовать простые функции, используя рекурсию (допускается использование дополнительных "внутренних" функций):
1. `def pascal(c: Int, r: Int): Int` — возвращает значение элемента треугольника Паскаля по номеру колонки и строки.
2. `def balance(chars: List[Char]): Boolean` — подсчитывает баланс скобок в выражении.
3. `def countChange(money: Int, coins: List[Int])` — определяет количество возможных вариантов размена суммы (money) монетами номиналом (coins).
4. `def nQueens(size: Int): Option[Array[Int]]` — принимает размер шахматной доски и возвращает решение по расстановке королев. Индекс массива — номер строки, значение — номер колонки. Отдельно реализована печать доски (1 - королева, 0 - пустая клетка).

## Описание решения:

### 1. Треугольник Паскаля (`pascal`)
Реализовано с использованием сопоставления с образцом (`match-case`) и рекурсии.
- Базовые случаи: края треугольника (`c == 0` или `c == r`) возвращают 1.
- Рекурсивный шаг: `pascal(c - 1, r - 1) + pascal(c, r - 1)`.
- Добавлена защита от некорректного ввода (если колонка или строка отрицательные, или колонка больше строки — возвращается 0).

### 2. Баланс скобок (`balance`)
Реализовано с использованием одного счетчика и `match-case`.
- Используется внутренняя рекурсивная функция со счетчиком.
- Ранний выход: если счетчик уходит в минус (закрывающая скобка появилась раньше открывающей), функция сразу возвращает `false`.
- Все остальные символы, кроме `(` и `)`, игнорируются.

### 3. Размен монет (`countChange`)
Классический рекурсивный перебор вариантов.
- Базовые случаи: если сумма отрицательная — 0 способов; если сумма равна 0 — 1 способ; если список монет пуст — 0 способов.
- Рекурсивный шаг: сумма двух ветвей (взять текущую монету или пропустить её и перейти к следующей).

### 4. Задача о N-ферзях (`nQueens`)
Реализовано в чисто функциональном стиле, без использования изменяемых массивов в процессе поиска.
- Проверка безопасности (`isSafeCheck`) использует рекурсию для проверки колонок и диагоналей.
- Поиск использует ленивый `Iterator` с методами `.filter`, `.map` и `.collectFirst`, чтобы остановиться на первом же найденном решении. Это экономит память и время.
- Результат возвращается в виде `Option[Array[Int]]`, как того требует задание.

## Результаты работы:
Метод `main` демонстрирует работу всех функций. В консоль выводится:
- Треугольник Паскаля (строки с 0 по 10).
- Тесты баланса скобок: `true, true, false, false`.
- Количество вариантов размена: `countChange(4, List(1, 2)) = 3` и `countChange(300, List(5, 10, 20, 50)) = 680`.
- Решение задачи N-ферзей для доски 4х4 (вывод доски с 1 и 0).
