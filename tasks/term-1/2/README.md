# Scala: misc

В данном задании реализованы простые функции с использованием рекурсии (используются дополнительные "внутренние" функции).

## Функции

* `def pascal(c: Int, r: Int): Int` - возвращает значение элемента треугольника Паскаля по номеру колонки и строки. Крайние элементы равны 1, остальные - сумма двух элементов строкой выше.
* `def balance(chars: List[Char]): Boolean` - подсчитывает баланс скобок в выражении (по открытым и закрытым скобкам `()`, `[]`, `{}`). Выражение сбалансировано, если каждой открывающей скобке соответствует закрывающая того же вида и они закрываются в правильном порядке.
* `def countChange(money: Int, coins: List[Int]): Int` - определяет количество возможных вариантов размена суммы `money` монетами номиналом `coins`. Варианты делятся на те, где используется первая монета, и те, где она не используется.
* `def nQueens(size: Int): Option[Array[Int]]` - принимает размер шахматной доски и возвращает расстановку такого же количества ферзей, при которой они не бьют друг друга (перебор с возвратом). Результат - массив номеров колонок, где размещён ферзь, индекс является номером строки. Если решения нет, возвращается `None`.
  * `def printBoard(queens: Array[Int]): Unit` - печать доски, где `1` - ферзь, `0` - пустая клетка.
