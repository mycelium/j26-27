# Scala: Recursive Functions

Программа на Scala с реализацией четырёх задач с использованием рекурсии.

### 1. Pascal's Triangle

Функция `pascal(c, r)` вычисляет значение элемента треугольника Паскаля по номеру строки и колонки.

Используется рекурсивная формула: каждый внутренний элемент равен сумме двух элементов, расположенных над ним. Первый и последний элементы каждой строки равны 1.

### 2. Parentheses Balancing

Функция `balance(chars)` проверяет правильность расстановки круглых скобок в выражении.

Рекурсивно просматриваются все символы списка. При встрече открывающей скобки счётчик увеличивается, при встрече закрывающей — уменьшается.
Если счётчик становится отрицательным, проверка завершается с результатом false.
Скобки расставлены правильно, если после обработки всех символов счётчик равен 0.

Остальные символы не влияют на результат.

### 3. Counting Change

Функция `countChange(money, coins)` вычисляет количество способов разменять заданную сумму монетами указанных номиналов.

На каждом шаге рассматриваются два варианта: использовать первую монету или пропустить её и перейти к следующему номиналу.
Рекурсия продолжается, пока сумма не станет равна нулю или пока не останется возможных вариантов.

### 4. N-Queens Problem

Функция `nQueens(size)` ищет способ разместить заданное количество королев на шахматной доске так, чтобы они не били друг друга.

Для решения используется рекурсивный перебор с возвратом (backtracking).
Королевы размещаются по одной в каждой строке. Перед размещением проверяется, что новая королева не находится в той же колонке или на одной диагонали с уже установленными королевами.

Если подходящее расположение найдено, функция возвращает массив номеров колонок. Если решения нет, возвращается `None`.

Для отображения результата используется функция `print_board`, которая печатает доску: `1` обозначает королеву, `0` — пустую клетку.

### Запуск программы

Для запуска проекта используется SBT:

```bash
sbt run
```

Программа выводит треугольник Паскаля, результаты проверки скобок, количество вариантов размена и решение задачи N-Queens.
