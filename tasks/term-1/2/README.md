# Лабораторная работа 2: Scala misc (Рекурсия)

В ходе выполнения работы были реализованы следующие функции с использованием рекурсии:

1. **`pascal(c, r)`**: Вычисляет значение треугольника Паскаля по номеру колонки и строки. База рекурсии: если колонка равна 0 или равна строке, возвращается 1. Иначе значение вычисляется как сумма двух элементов над текущим.
2. **`balance(chars)`**: Проверяет баланс скобок. Используется внутренняя хвостовая рекурсивная функция `loop`, которая хранит текущий счетчик открытых скобок. Если счетчик становится отрицательным, возвращается `false`. В конце проверяется, что счетчик равен 0.
3. **`countChange(money, coins)`**: Определяет количество вариантов размена суммы. Реализовано через рекурсивное разбиение задачи: либо мы берем текущую монету (уменьшаем сумму на ее номинал), либо переходим к следующей монете. База: если сумма 0 — 1 вариант, если сумма < 0 или монеты закончились — 0 вариантов.
4. **`nQueens(size)`**: Решает задачу о N ферзях. Реализован поиск с возвратом (backtracking). Вспомогательная функция `placeQueens` рекурсивно размещает ферзей построчно, а `isSafe` проверяет, не бьет ли новый ферзь уже размещенных (по вертикали и диагоналям). Дополнительно реализована функция `printBoard` для визуализации доски (1 - ферзь, 0 - пустая клетка).
