# Scala: Functional Sets

Программа на Scala с реализацией функциональных множеств целых чисел.

Множество представлено функцией `Set = Int => Boolean`, которая проверяет, содержится ли заданное число в множестве.

### Реализованные функции

- `contains` — проверка наличия элемента в множестве.
- `singletonSet` — создание множества из одного элемента.
- `union` — объединение двух множеств.
- `intersect` — пересечение двух множеств.
- `diff` — разность двух множеств.
- `filter` — создание подмножества по заданному условию.
- `forall` — проверка условия для всех элементов в заданных границах.
- `exists` — проверка наличия хотя бы одного элемента, удовлетворяющего условию.
- `map` — преобразование элементов множества с помощью заданной функции.
- `toString` и `printSet` — преобразование множества в строку и вывод на экран.

Для функций `forall` и `exists` используется диапазон от -1000 до 1000.
Функции `map`, `toString` и `printSet` также учитывают элементы только из этого диапазона.
