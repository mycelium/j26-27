# Лабораторная работа 3: Функциональное множество (Functional Set)

В данной работе множество целых чисел представлено как характеристическая функция (предикат) `type Set = Int => Boolean`. 

Были реализованы следующие операции:
- `singletonSet`: возвращает функцию, которая истинна только для заданного элемента.
- `union`, `intersect`, `diff`: реализованы через логические операторы над результатами вызова функций-множеств.
- `filter`: возвращает новое множество, комбинируя проверку на принадлежность исходному множеству и применение предиката.
- `forall` и `exists`: реализованы с помощью итеративного перебора целых чисел в заданных границах `[-bound, bound]` с использованием хвостовой рекурсии.
- `map`: возвращает множество, которое содержит элемент `x`, если в исходном множестве существует элемент `y`, для которого `f(y) == x`.

**Где хранятся элементы множества?**
В данной реализации элементы множества нигде физически не хранятся в памяти в виде массива или списка. Множество — это математическая абстракция, заданная логическим условием (функцией). Мы можем лишь "проверить" принадлежность конкретного числа к множеству, передав его в функцию, или перебрать ограниченный диапазон чисел, чтобы найти те, для которых функция возвращает `true`.
