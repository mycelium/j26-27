# Задание 3. Scala: Functional Set

## Задача

Реализовать множество целых чисел, заданное как функция:

```scala
type Set = Int => Boolean
```

Функция отвечает на вопрос «содержится ли число в множестве». Нужно было написать функции, тело которых в шаблоне было `???`.

## Как запустить

Из папки `tasks/term-1/3`:

```bash
scala-cli run src/main/scala --scala 2.12
```

`Main.scala` проверяет все функции на множестве `{1, 2, 3}` и печатает результаты.

## Реализованные функции

| Функция | Что делает | Как устроена |
|---|---|---|
| `singletonSet(elem)` | множество из одного числа | `x => x == elem` |
| `union(s, t)` | объединение | `x` есть в `s` **или** в `t` |
| `intersect(s, t)` | пересечение | `x` есть **и** в `s`, **и** в `t` |
| `diff(s, t)` | разность | `x` есть в `s`, но **не** в `t` |
| `filter(s, p)` | элементы `s`, для которых верно условие `p` | `x` есть в `s` **и** `p(x)` |
| `forall(s, p)` | верно ли `p` для всех элементов `s` | рекурсивный перебор чисел от −1000 до 1000 |
| `exists(s, p)` | есть ли элемент, для которого верно `p` | через `forall`: «неправда, что для всех `p` ложно» |
| `map(s, f)` | множество `{f(x) : x ∈ s}` | `y` в результате, если в `s` есть `x`, что `f(x) == y` |

Каждая операция не перечисляет элементы, а **создаёт новую функцию**, которая при вызове спрашивает исходные множества.

## Результат

```
true          contains(singletonSet(1), 1)
false         contains(singletonSet(1), 2)
{1,2}         union
{1}           intersect
{2}           diff
{1,3}         filter: нечётные
true          forall: все > 0
false         forall: все < 3
true          exists: есть > 2
false         exists: есть > 10
{10,20,30}    map: x * 10
{1,4,9}       map: x * x
```

## Где хранятся элементы множества

**Они не хранятся как отдельные данные.** Множество здесь — это функция.

Числа хранятся внутри **замыканий**: функция «запоминает» переменные из того места, где её создали.

- `singletonSet(1)` создаёт функцию `x => x == 1`. Число `1` хранится внутри неё.
- `union(s1, s2)` создаёт функцию, которая хранит **ссылки** на `s1` и `s2` и при вызове спрашивает их обе.

Получается дерево функций, а сами числа лежат в его листьях. Ответ на вопрос «лежит ли число в множестве» каждый раз вычисляется заново по этому дереву.
