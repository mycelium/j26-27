# Лабораторная работа № 3. Функциональные множества

Множество целых чисел представлено функцией-предикатом:

```scala
type Set = Int => Boolean
```

Функция принимает число и возвращает `true`, если оно принадлежит множеству. Например, множество с единственным элементом `1` задаётся так:

```scala
value => value == 1
```

Для операций, которым необходимо перебирать возможные элементы, используется диапазон от `-1000` до `1000`.

## Где хранятся элементы множества?

Элементы не хранятся в массиве или коллекции. Множество задаётся функцией проверки принадлежности. Конкретные значения и другие функции, из которых составлено множество, сохраняются в её замыкании.
