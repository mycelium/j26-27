### Реализация
Реализованы следующие функции:
- singletonSet(elem) — множество из одного элемента elem. Возвращает предикат x == elem.
- union(s, t) — объединение двух множеств. Реализовано через ИЛИ.
- intersect(s, t) — пересечение двух множеств. Реализовано через И.
- diff(s, t) — разность множеств (s без элементов t). Реализовано через И НЕ.
- filter(s, p) — подмножество элементов s, удовлетворяющих предикату p. Ищет элементы s для которых верно p.
- forall(s, p) — проверка: все ли элементы s удовлетворяют p. Ищет контрпример в диапазоне +-1000.
- exists(s, p) — проверка: есть ли в s хотя бы один элемент, удовлетворяющий p. Реализован через проверку, что есть хотя бы 1 элемент, который не удовлетворяет НЕ(p) (инвертирует forall по закону Де Моргана).
- map(s, f) — применение функции f к каждому элементу s. Для каждого итогового y ищет прообраз x в s, такой что f(x) == y

### Где хранятся элементы множества?

Сами элементы нигде не хранятся. Множество -- это предикат, правило, по которому мы определяем, что элемент ему принадлежит.
