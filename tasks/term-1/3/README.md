Элементы множества нигде не хранятся в виде готовой структуры данных (массива, списка и т.д.).
 Множество в этой реализации — это просто функция, которая проверяет, принадлежит ли число множеству.
 Когда мы объединяем множества, мы не переносим элементы, а создаем новую функцию, которая просто вызывает старые.
 Таким образом, элементы хранятся в самой логике функций.
