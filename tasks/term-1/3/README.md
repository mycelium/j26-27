- После выполнения задания, подумайте над тем, где все-таки хранятся элементы множества

## Где хранятся элементы множества?

Нигде. В функциональном программировании данные и поведение неразделимы. Здесь мы не храним сами числа. Вместо этого мы храним логику, по которой можно определить, принадлежит ли число множеству.
