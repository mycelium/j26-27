### 3. Scala: Functional Set

Постановка задачи:
- В этом задании необходимо реализовать множество целых чисел заданное как функцию type Set = Int => Boolean, данная функция отвечает на вопрос "содержится ли заданный элемент в множестве", выделяя его таким образом из множества целых чисел
- Для выполнения задания необходимо представить свою реализацию функций, тело которых представлено как ???
- После выполнения задания, подумайте над тем, где все-таки хранятся элементы множества

### Реализация

* `def singletonSet(elem: Int): Set` -- множество из одного заданного элемента.
* `def union(s: Set, t: Set): Set` -- объединение множеств: все элементы, которые есть в `s` или в `t`.
* `def intersect(s: Set, t: Set): Set` -- пересечение множеств: элементы, которые есть и в `s`, и в `t`.
* `def diff(s: Set, t: Set): Set` -- разность множеств: элементы `s`, которых нет в `t`.
* `def filter(s: Set, p: Int => Boolean): Set` -- подмножество `s`, элементы которого удовлетворяют условию `p`.
* `def forall(s: Set, p: Int => Boolean): Boolean` -- проверка, что все элементы `s` (в границах `±bound`) удовлетворяют условию `p`.
* `def exists(s: Set, p: Int => Boolean): Boolean` -- проверка, что в `s` (в границах `±bound`) есть элемент, удовлетворяющий условию `p`.
* `def map(s: Set, f: Int => Int): Set` -- множество, полученное применением функции `f` к каждому элементу `s`.

Границы для `forall` и `exists`: `bound = 1000`, то есть проверяются числа от -1000 до 1000.

Множество представлено своей характеристической функцией: `s(x)` возвращает `true`, если число `x` принадлежит множеству. Поэтому каждая операция над множествами возвращает новую функцию `x => ...`, в которой условие принадлежности результату выражено через `s(x)`, `t(x)` и `p(x)`.

## Где хранятся элементы множества

Множество в этом задании не хранит ни одного числа: это только правило (функция), которое по числу отвечает "входит или не входит".

* Пример; `singletonSet(1)` -- в куче JVM создается объект-функция типа Int => Boolean. У этого объекта есть служебное поле, в которое при создании копируется значение elem, то есть 1.
