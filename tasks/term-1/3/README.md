# Scala: Functional Set

Множество целых чисел, заданное характеристической функцией:

```scala
type Set = Int => Boolean
```

Функция отвечает на вопрос «содержится ли заданное число в множестве». Все операции над множествами реализованы в `object FunSets` (файл `src/main/scala/funsets/FunSets.scala`).

## Запуск

```bash
scala-cli run src/main/scala --scala 2.13 --main-class funsets.Main
```

## Где хранятся элементы множества

Нигде. Значение типа `Set` это не набор чисел, а правило, по которому для числа вычисляется ответ «да» или «нет».

## Проверка

В `Main.scala` проверяются все операции: принадлежность элементов после `singletonSet`, `union`, `intersect`, `diff` и `filter`, граничные значения `±1000` для `forall` и `exists`, пустое множество (`forall` на нём истинно, `exists` ложно), а также результат `map` через `toString`.

## Ограничения

- `forall`, `exists` и `toString` работают только на диапазоне `[-1000, 1000]`; элементы за его пределами они не видят.
- Множества не хранят элементов, поэтому получить их размер или список можно только полным перебором диапазона.
