- После выполнения задания, подумайте над тем, где все-таки хранятся элементы множества


### Реализация функций

- `singletonSet` создаёт множество из одного заданного элемента.
- `union` объединяет два множества: элемент должен быть хотя бы в одном из них.
- `intersect` оставляет элементы, которые есть в обоих множествах.
- `diff` оставляет элементы первого множества, которых нет во втором.
- `filter` оставляет элементы множества, подходящие под условие `p`.
- `forall` рекурсивно проверяет числа от `-1000` до `1000`: все элементы множества должны подходить под условие `p`.
- `exists` реализована через отрицание `forall` по закону де Моргана.
- `map` включает `y`, если существует исходный элемент `x`, для которого `f(x) == y`.

### Хранение элементов множества

Значение типа `Set` --- функция `Int => Boolean`: она получает число и отвечает, принадлежит ли оно множеству. **Итог**: элементы не хранятся как массив / коллекция, вместо этого имеется правило, по которому определяется, принадлежит ли элемент множеству.
