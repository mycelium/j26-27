# Scala: функциональное множество

Множество задано функцией `Int => Boolean`, поэтому все операции возвращают новую функцию:
- `singletonSet` — `x == elem`;
- `union`, `intersect`, `diff`, `filter` — сочетание условий через `||`, `&&` и `!`;
- `forall` — рекурсивный перебор чисел от -1000 до 1000, ищет элемент множества, не подходящий под `p`;
- `exists` — через `forall`: элемент найдётся, если не все элементы не подходят;
- `map` — `y` входит в результат, если есть `x` из множества, у которого `f(x) == y`.

Где хранятся элементы: явно — нигде. Множество — это правило, а не набор данных. Значения
(`elem`, исходные множества `s` и `t`) захватываются замыканиями функций-лямбд, которые лежат в куче.
Элемент «появляется» только при вызове функции с конкретным числом.
