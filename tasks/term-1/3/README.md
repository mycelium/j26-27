# 3. Scala: Functional Set

**Файлы:**
- `FunSets.scala` — реализация чисто функциональных множеств.
- `Main.scala` — тесты для проверки работы функций.

## Постановка задачи
В этом задании необходимо реализовать множество целых чисел, заданное как функция `type Set = Int => Boolean`. Данная функция отвечает на вопрос: "содержится ли заданный элемент в множестве?".

## Детали реализации

1. **`singletonSet`**: Возвращает предикат, который истинен только для заданного элемента.
2. **`union`, `intersect`, `diff`, `filter`**: Реализованы с использованием ленивых логических операций (`||`, `&&`, `!`), применяемых к предикатам. Сами элементы при этом не хранятся.
3. **`forall`**: Использует внутренний рекурсивный цикл для проверки того, что все элементы множества удовлетворяют условию `p`. Возвращает `false` досрочно, если находит элемент, не удовлетворяющий условию.
4. **`exists`**: Реализована через законы де Моргана как `!forall(s, x => !p(x))`. Это математически элегантный и классический подход в функциональном программировании.
5. **`map`**: Возвращает новое множество, в котором для каждого элемента `x` проверяется, существует ли в исходном множестве `s` такой элемент `a`, что `f(a) == x`.

Элементы **не хранятся в оперативной памяти**. Множество — это просто правило (булева функция). Мы не храним сами числа; мы храним только логику, которая может определить, принадлежит ли число множеству. Элементы «вычисляются» на лету в тот момент, когда функция вызывается.
