# FunSets

Множество целых чисел задаётся функцией `Int => Boolean`: для любого числа она отвечает, входит ли оно в множество.

Операции (`union`, `intersect`, `diff`, `filter`, `map`) не создают коллекций — они возвращают новую функцию, которая проверяет условие через исходные множества.

`forall` и `exists` перебирают числа от -1000 до 1000, потому что функцию нельзя перебрать целиком.

## Где хранятся элементы?

Элементы нигде не хранятся. Хранится только правило проверки и значения, которые лямбда запомнила при создании. Элемент появляется только при вызове функции с конкретным числом.
