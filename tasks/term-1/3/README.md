Functional Sets

Проект реализует работу с множествами целых чисел на языке Scala с использованием функционального программирования.
Множество представляется функцией типа Int => Boolean, которая определяет, принадлежит ли переданное число множеству.
Реализованные функции

contains — проверка принадлежности элемента множеству.
singletonSet — создание множества из одного элемента.
union — объединение двух множеств.
intersect — пересечение множеств.
diff — разность множеств.
filter — фильтрация элементов по условию.
forall — проверка условия для всех элементов.
exists — проверка наличия хотя бы одного элемента, удовлетворяющего условию.
map — применение функции ко всем элементам множества.
toString и printSet — преобразование множества в строку и вывод на экран.
