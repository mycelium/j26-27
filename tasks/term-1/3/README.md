Элементы множества не хранятся в отдельной коллекции. Множество представлено функцией Int => Boolean, которая определяет, входит ли заданное число в него. Значения, необходимые этой функции, сохраняются в замыкании. Например, функция для одноэлементного множества запоминает его число. Поэтому элементы заданы логикой функции, а не перечислены в списке.
