Элементы множества не хранятся в виде списка или массива. Вместо этого множество задаётся функцией, которая принимает целое число и возвращает true, если оно принадлежит множеству, и false в противном случае. Таким образом, мы храним не сами числа, а правило, по которому можно определить, входит ли число в множество. Проверка принадлежности выполняется на лету, при вызове функции.
