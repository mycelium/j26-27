## Множество ничего не хранит

Множество задано как тип **type Set = Int => Boolean**. Это не коллекция с элементами, а функция, которая отвечает на вопрос входит ли число в множество?

Элементы множества нигде не лежат в памяти, хранятся только функции. Вместо списка элементов множество задается условием на число, записанным в теле функции. Например, при создании **singletonSet(1)** создается функция **x => x == 1**: она возвращает **true** только для числа 1, а для любого другого **false**.

Каждый вызов **singletonSet** создает в куче новый объект-функцию, а переменная в стеке хранит лишь ссылку на него. Число 1 при этом не элемент множества, а параметр, который объект запоминает внутри себя, чтобы сравнивать с ним входное число.

Функции, построенные через **union**, **intersect** и другие операции, тоже создаются в куче как отдельные объекты, но запоминают не числа, а ссылки на исходные функции. Так получается цепочка объектов-функций, в конце которой лежат параметры вроде **1**, и вызов проверки проходит по этой цепочке.
