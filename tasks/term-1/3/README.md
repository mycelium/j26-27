Элементы множества не хранятся в отдельной коллекции. Множество представлено функцией `Int => Boolean`, которая по числу определяет, принадлежит ли оно множеству. В памяти хранится объект функции и значения, захваченные её замыканием, например, `singletonSet(5)` сохраняет число `5`, а `union(s, t)` — ссылки на функции `s` и `t`. Таким образом, состав множества задаётся правилом проверки принадлежности, а для перечисления его элементов программа перебирает числа в выбранном диапазоне и оставляет те, для которых функция возвращает `true`.
