В итоге элементы множества физически нигде не хранятся (в качестве списка или массива). 
Множество представляет собой функцию-правило принадлежности элемента множеству, а операции над множеством - цепочку функций, 
которые запоминают нужные значения в захваченных переменных. 
Проверка выполняется каждый раз заново при вызове.
