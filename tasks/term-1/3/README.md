## Где хранятся элементы множества

Множество не содержит элементов в привычном смысле — нет ни списка,
ни массива, где они лежали бы. Вместо этого оно представлено функцией:
ей передаётся целое число, и она отвечает `true`, если число входит
в множество, либо `false`, если не входит. То есть вместо самих чисел
мы храним условие, позволяющее для любого числа определить его
принадлежность. Эта проверка не выполняется заранее — она происходит
в момент вызова функции.
