### Реализация функций

- **singletonSet** - множество из одного элемента. Возвращает функцию `x => x == elem`, которая истинна только для заданного `elem`.

- **union** - объединение двух множеств. Элемент принадлежит объединению, если он содержится хотя бы в одном из них: `x => s(x) || t(x)`.

- **intersect** - пересечение двух множеств. Элемент принадлежит пересечению, только если он содержится в обоих: `x => s(x) && t(x)`.

- **diff** - разность множеств (элементы `s`, которых нет в `t`): `x => s(x) && !t(x)`.

- **filter** - подмножество `s`, элементы которого удовлетворяют предикату `p`: `x => s(x) && p(x)`.

- **forall** - проверяет, что **все** элементы `s` из диапазона `[-bound, bound]` удовлетворяют предикату `p`. Используется внутренняя функция `iter`, которая проходит от `-bound` до `bound` включительно: если дошли до конца - `true`; если нашли элемент из `s`, не удовлетворяющий `p`, - `false`.

- **exists** - проверяет, что **существует** элемент `s`, удовлетворяющий `p`. Реализован через `forall` с двойным отрицанием: `!forall(s, x => !p(x))`.

- **map** - преобразованное множество: каждый элемент `x` из `s` заменяется на `f(x)`. Возвращает функцию `y => exists(s, x => f(x) == y)`: элемент `y` принадлежит результату, если в `s` найдётся такой `x`, что `f(x) == y`.

### Где хранятся элементы множества

**Нигде.** В этой реализации множество не хранит элементы в памяти — оно **представлено функцией**, которая для любого целого числа возвращает `true` или `false`.
