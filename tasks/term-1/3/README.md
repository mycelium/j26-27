Множество здесь задано функцией `Int => Boolean`: она отвечает, входит ли число в множество. Отдельного списка с элементами нет. Например, `singletonSet` возвращает функцию, которая захватывает заданное число, а `union` и `filter` проверяют элементы через исходные функции.

Для `forall`, `exists`, `map` и `toString` используется диапазон от `-bound` до `bound`. Поэтому эти операции проверяют только его, хотя отдельная функция-множество может отвечать и для чисел за пределами диапазона.
