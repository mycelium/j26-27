## 3. Scala: Functional Set

В этой лабораторной множество целых чисел хранится не как список или массив, а как функция:

```scala
type Set = Int => Boolean
```

Такая функция получает число и отвечает на вопрос «есть ли это число в множестве?»: `true` — есть, `false` — нет. Например, множество чётных чисел — это функция `x => x % 2 == 0`.

Запуск (из папки `3`):
```bash
scala run src/main/scala
```

### Как реализованы функции

- **`singletonSet(elem)`** — множество из одного числа. Возвращает функцию, которая говорит `true` только для `elem`: `x => x == elem`.
- **`union(s, t)`** — объединение. Число входит в результат, если оно есть в `s` **или** в `t`.
- **`intersect(s, t)`** — пересечение. Число входит в результат, если оно есть и в `s`, **и** в `t`.
- **`diff(s, t)`** — разность. Число есть в `s`, но **нет** в `t`.
- **`filter(s, p)`** — оставляет из `s` только те числа, для которых условие `p` верно.
- **`forall(s, p)`** — проверяет, что условие `p` верно для **всех** чисел множества. Проверить все целые числа невозможно, поэтому проверяются только числа от -1000 до 1000 (`bound`). Вспомогательная функция `iter` с помощью рекурсии идёт по числам от -1000 вверх:
  - если дошли до числа больше 1000, значит, ничего плохого не нашли, ответ `true`;
  - если число есть в множестве, но условие для него неверно, ответ `false`;
  - иначе проверяем следующее число.
- **`exists(s, p)`** — проверяет, что **хотя бы одно** число множества подходит под условие `p`. Сделано через `forall`: «существует подходящее число» — это то же самое, что «неправда, что все числа не подходят».
- **`map(s, f)`** — множество, где к каждому элементу применили функцию `f`. Число `y` входит в результат, если в `s` есть такое `x`, что `f(x) == y`. Это проверяется через `exists`.

Также в функции `printSet` из шаблона исправлена запись `def printSet(s: Set) {` на `def printSet(s: Set): Unit = {`, потому что новая версия Scala старую запись не принимает.

### Результат работы

```
contains(s1, 1): true
contains(s1, 2): false
union {1,2} и {3}: {1,2,3}
intersect {1,2} и {2,3}: {2}
diff {1,2,3} и {2}: {1,3}
filter {1,2,3}, x > 1: {2,3}
forall {1,2,3}, x > 0: true
forall {1,2,3}, x > 1: false
exists {1,2,3}, x == 2: true
exists {1,2,3}, x > 5: false
map {1,2,3}, x * 10: {10,20,30}
```

### Где хранятся элементы множества?

На самом деле элементы нигде не хранятся в обычном смысле: нет ни списка, ни массива с числами. Множество — это **правило**, по которому можно проверить любое число.

Когда мы вызываем `singletonSet(1)`, создаётся функция `x => x == 1`. Число `1` она «запомнила» внутри себя: такая функция вместе с запомненными значениями называется **замыканием**. Когда мы делаем `union(s1, s2)`, новая функция запоминает уже не числа, а сами функции `s1` и `s2` и при проверке спрашивает каждую из них. Получается цепочка функций, вложенных друг в друга. Можно сказать, что элементы «хранятся» в коде этих функций и в значениях, которые они запомнили.

Из-за этого:
- можно задать даже бесконечное множество, например все положительные числа: `x => x > 0`;
- но нельзя просто перебрать все элементы, поэтому `forall`, `exists` и `printSet` смотрят только числа от -1000 до 1000.
