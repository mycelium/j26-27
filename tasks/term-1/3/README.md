## Множество ничего не хранит

Множество задано как тип **type Set = Int => Boolean**. Это не коллекция с элементами, а функция, которая отвечает на вопрос входит ли число в множество?

Числа нигде не лежат в памяти. Вместо списка элементов множество задается условием на число, записанным в теле функции. Например, множество из одного элемента 1 это функция **x => x == 1**: она возвращает **true** только для числа 1, а для любого другого **false**.
