### Где хранятся элементы множества?

Здесь мы не складываем элементы в массив или список, а задаём функцию,
которая проверяет, входит ли число в множество. Например, `singletonSet(5)`
возвращает `x => x == 5`. Эта функция запоминает число 5 и сравнивает с ним
переданный аргумент. А `union` запоминает два множества и проверяет оба.

Получается, в памяти хранятся функции и нужные им значения. Перечислять все
элементы не нужно: например, для множества чётных чисел достаточно проверки
`x % 2 == 0`.
