# Лабораторная работа № 4. Подсчёт частоты слов

Подсчёт реализован двумя способами:

- `countWordsInMemory` загружает файл целиком в память;
- `countWordsStreaming` читает файл блоками по 8192 символа.

Оба метода передают символы в один и тот же `WordFrequencyProcessor`, поэтому используют одинаковые правила выделения слов.

## Обработка слов

`WordFrequencyProcessor` реализован как конечный автомат. Он хранит текущее слово, таблицу частот и состояние обработки между полученными блоками текста.

Автомат использует следующие состояния:

- `BETWEEN_WORDS` — ожидает начало следующего слова;
- `READING_WORD` — добавляет буквы и цифры к текущему слову;
- `AFTER_HYPHEN` — определяет, является ли дефис частью слова или переносом;
- `AFTER_HYPHEN_CARRIAGE_RETURN` — обрабатывает первую часть переноса `\r\n`;
- `AFTER_HYPHEN_LINE_BREAK` — продолжает слово после переноса строки.

Слова приводятся к нижнему регистру. Дефис внутри строки сохраняется, а дефис перед переносом строки удаляется, чтобы части перенесённого слова объединились. Граница блока не завершает слово: автомат сохраняет состояние до следующего вызова.

## Запуск

Программа принимает режим обработки и путь к файлу:

```text
java WordFrequencyCounter <memory|stream|compare> <файл>
```

- `memory` загружает файл целиком;
- `stream` читает файл блоками;
- `compare` запускает оба способа и проверяет совпадение результатов.

Например, после компиляции можно сравнить способы на небольшом README:

```bash
java -cp /tmp/j26-java WordFrequencyCounter compare README.md
```

Для большого файла используется потоковый режим с ограничением памяти:

```bash
java -Xmx64m -cp /tmp/j26-java WordFrequencyCounter stream large-test.xml
```

## Результаты проверки

На `tasks/term-1/README.md` оба способа получили одинаковый результат: 511 слов и 341 уникальное слово.

Для проверки потоковой обработки использован UTF-8 XML с русскими текстами Civilization VI, повторённый 87 раз. Полученный `large-test.xml` 505 МиБ, и не добавляется в Git.

Потоковый способ обработал файл за 4489 мс. Было найдено 49 445 058 слов, из них 63 831 уникальное. Загрузка файла целиком с тем же ограничением завершилась с `OutOfMemoryError` в `Files.readString`.
