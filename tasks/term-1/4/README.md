# Лабораторная работа 4: Word Frequency Counter

Приложение для подсчета частоты слов в текстовом файле реализовано в двух вариантах:

1. **Загрузка всего файла в память (`countWordsInMemory`)**: Весь файл считывается в строку с помощью `Files.readAllBytes`, после чего строка разбивается на слова (с приведением к нижнему регистру и удалением знаков препинания регулярным выражением `[^a-zA-Z]+`). Этот метод быстрый, но потребляет объем памяти, равный размеру файла (и даже больше из-за накладных расходов на String).
2. **Потоковая обработка (`countWordsStreaming`)**: Файл читается построчно с помощью `BufferedReader`. Каждая строка обрабатывается, а результаты сразу агрегируются в `HashMap` с помощью метода `merge`. Этот подход позволяет обрабатывать файлы размером больше доступной оперативной памяти, так как в каждый момент времени в памяти хранится только одна строка из файла и сам словарь частот.

Для вывода результатов реализован метод `printFrequencies`, который сортирует словарь по убыванию частоты встречаемости и выводит топ-20 слов.
