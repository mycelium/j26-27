Программа считает, сколько раз каждое слово встречается в текстовом файле (UTF-8).
Слово — последовательность букв и цифр, регистр не учитывается.

Запуск:

```
javac WordFrequencyCounter.java
java WordFrequencyCounter <file> <full|stream>
```

## `countWords` (режим `full`)

Весь файл читается в память одной строкой, приводится к нижнему регистру и режется на слова
(всё, кроме букв и цифр, — разделители). Для каждого непустого слова в `HashMap` увеличивается счётчик.

## `countWordsStreaming` (режим `stream`)

Файл читается блоками по 8192 символа, а не построчно: текст может быть одной огромной строкой,
и тогда построчное чтение загрузило бы в память весь файл.

Слово собирается по символам: буква или цифра добавляется к слову, любой другой символ завершает его,
и оно записывается в `HashMap`.

## Проверка

На файле `test_text.txt` оба режима дают одинаковые результаты.
