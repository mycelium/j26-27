### 4. Java: Word Frequency Counter

Постановка задачи:
- Реализовать подсчет частоты слов в текстовом файле в двух вариантах:
  - Загрузка всего содержимого файла с последующей обработкой
  - Потоковая обработка файла (программа должна обрабатывать файлы большего объема, чем доступная оперативная память)
- Выводить результат работы подсчета

## Реализация

Слово это последовательность букв и цифр, регистр не учитывается. Частоты хранятся в `TreeMap<String, Integer>`, поэтому результат выводится в алфавитном порядке.

* `addWords(frequencies, text)` -- общий метод для обоих вариантов: переводит текст в нижний регистр, разбивает его на слова по любым символам, кроме букв и цифр, и увеличивает счётчик каждого слова.
* `countWords(path)` -- загрузка всего файла: `Files.readString` читает файл целиком в одну строку, которая передаётся в `addWords`. Объём памяти пропорционален размеру файла.
* `countWordsStreaming(path)` -- потоковая обработка: файл читается по символам через `BufferedReader`, символы накапливаются в строке `line`. Когда встречается перевод строки, накопленный текст передаётся в `addWords` и очищается. Если перевода строки нет в течение `MAX_LINE_LENGTH` (10 000) символов, текст обрабатывается принудительно на ближайшем символе, не являющемся буквой или цифрой (чтобы не разрезать слово). Это защищает от файлов, целиком записанных в одну строку. В памяти хранятся только текущая "строка" и словарь частот, поэтому объём памяти зависит от числа уникальных слов, а не от размера файла.
* `printFrequencies(frequencies)` -- печатает пары `слово: количество`.

Запуск (`stream` включает потоковый вариант, без него используется загрузка всего файла):

```
java WordFrequencyCounter.java text.txt stream
java WordFrequencyCounter.java text.txt
```

## Тест с ограничением памяти

Память JVM ограничивается флагом `-Xmx`, который задаёт максимальный размер кучи. Обе версии запускались на файле `text.txt` с ограничением 64 МБ.

-rw-r--r--  1 klebedevich  staff   105M Oct 25 23:42 text.txt -- размер тестового файла.

**Потоковая обработка** -- файл обработан, результат выведен (первые строки):

```
java -Xmx64m WordFrequencyCounter.java text.txt stream | head
1: 12350
10: 37050
11: 12350
12: 12350
1990: 12350
1994: 12350
1995: 12350
2: 12350
2000: 12350
2020: 12350
```

**Загрузка всего файла** -- файл не помещается в память, программа завершается с ошибкой:

```
java -Xmx64m WordFrequencyCounter.java text.txt
Exception in thread "main" java.lang.OutOfMemoryError: Java heap space
        at java.base/java.nio.file.Files.readString(Files.java:3043)
        at WordFrequencyCounter.countWords(WordFrequencyCounter.java:16)
```

Вывод: потоковый вариант обрабатывает файл, превышающий доступную память, а вариант с полной загрузкой на нём аварийно завершается.
