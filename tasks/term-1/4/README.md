В лабораторной реализованы два варианта подсчёта частот слов. `countWordsWholeFile` загружает весь файл в память, а `countWordsStreaming` читает его буфером и обрабатывает по мере чтения.

Для запуска перейдите в папку `4` и выполните `javac WordFrequencyCounter.java`. Затем укажите файл командой `java WordFrequencyCounter --file "путь/к/файлу.txt"`. Для большого файла добавьте `--streaming-only`, чтобы запустить только потоковый вариант. Если файл не указан, используется `artifacts/text.txt`; результаты сохраняются в `artifacts/`.
