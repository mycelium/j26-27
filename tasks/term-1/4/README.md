# Подсчёт частоты слов

## Сборка и запуск

```bash
javac WordFrequencyCounter.java
java WordFrequencyCounter <файл> [full|stream]
```

- `full` — загрузка всего файла с последующей обработкой;
- `stream` — потоковая обработка (по умолчанию).

Для корректного вывода русских слов в консоли Windows: `java -Dstdout.encoding=UTF-8 WordFrequencyCounter <файл>`.

## Что сделано

- Словом считается последовательность букв и цифр, регистр не учитывается.
- `countWords` — читает файл целиком через `Files.readString`, делит текст на слова и считает их в `HashMap`.
- `countWordsStreaming` — `Scanner` читает файл небольшими порциями и выдаёт по одному слову,
  в памяти хранится только таблица уникальных слов. Поэтому файл может быть больше доступной памяти.
- `printFrequencies` — печатает слова по убыванию частоты и число уникальных слов.

## Проверка

Файл 400 МБ при ограничении памяти `-Xmx64m`:
- `full` — падает с `OutOfMemoryError`;
- `stream` — отрабатывает (~55 с).

На файле 20 МБ оба варианта дают одинаковый результат.
