### 4. Java: Word Frequency Counter

#### Постановка задачи:

- Реализовать подсчет частоты слов в текстовом файле в двух вариантах:
  - Загрузка всего содержимого файла с последующей обработкой
  - Потоковая обработка файла (программа должна обрабатывать файлы большего объема, чем доступная оперативная память)
- Выводить результат работы подсчета

#### Режимы работы
- Обработка в памяти (countWordsMemory). Загружает весь текст файла в оперативную память. Подходит для быстрых операций с небольшими файлами.
- Потоковая обработка (countWords). Читает файл последовательно через Scanner. Позволяет обрабатывать файлы, чей размер превышает доступный объем оперативной памяти.
