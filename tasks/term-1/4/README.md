# Word Frequency Counter

Программа на Java для подсчёта частоты слов в текстовом файле.

Реализованы два способа обработки:

1) загрузка всего содержимого файла в память с последующим подсчётом слов;
2) потоковая обработка файла построчно с помощью BufferedReader.

Программа приводит слова к нижнему регистру, удаляет знаки пунктуации и подсчитывает количество вхождений каждого слова с помощью HashMap.

После обработки выводятся результаты обоих методов и проверяется, что результаты совпадают.

Для запуска необходимо поместить файл `file.txt` в рабочую директорию, скомпилировать программу командой:

```bash
javac WordFrequencyCounter.java
```

Запустить программу:

```bash
java WordFrequencyCounter
```
