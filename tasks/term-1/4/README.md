# 4. Java: Word Frequency Counter

**Файлы:**
- `WordFrequencyCounter.java` — реализация подсчета частоты слов.
- `README.md` — описание решения.

## Постановка задачи
Реализовать подсчет частоты слов в текстовом файле в двух вариантах:
1. Загрузка всего содержимого файла в память.
2. Потоковая обработка файла (для файлов, превышающих объем ОЗУ).
3. Вывод результата.

## Детали реализации

### 1. Загрузка в память (`--file`)
Файл целиком читается в строку (`Files.readString`). Затем строка разбивается на слова с помощью регулярного выражения, и частоты считаются в `HashMap`. Подходит для небольших файлов.

### 2. Потоковая обработка (`--stream`)
Файл читается посимвольно через `BufferedReader` с буфером на 8192 символа.
- Если символ является буквой или цифрой, он добавляется в `StringBuilder` (текущее слово).
- Если символ является разделителем, слово сохраняется в `HashMap`, а буфер очищается.
  Данный подход не создает промежуточных массивов строк (как метод `split`), поэтому потребление памяти остается минимальным и постоянным, независимо от размера файла.

## Использование
- `java WordFrequencyCounter --file <path>` — режим загрузки в память.
- `java WordFrequencyCounter --stream <path>` — потоковый режим.
