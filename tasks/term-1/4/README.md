В этой лабе считаются частоты слов двумя способами: `countWordsWholeFile` сначала загружает весь файл в память, а `countWordsStreaming` читает его кусками через буфер на 8192 символа и сразу обновляет счётчики. По умолчанию регистр игнорируется: `Java` и `java` считаются одним словом. Потоковый вариант не хранит весь текст, но таблица частот всё равно хранится в памяти.

Запускать команды надо из папки `4`: `javac WordFrequencyCounter.java`, затем `java WordFrequencyCounter`. По умолчанию программа читает `artifacts/text.txt`, сохраняет оба результата в `artifacts/` и проверяет, совпали ли они. Для другого файла укажи `--file "путь к файлу"`; если файл большой и его нельзя целиком загрузить в память, добавь `--streaming-only`, например: `java WordFrequencyCounter --file "путь к файлу" --streaming-only`.

В `artifacts/` лежат входной пример `text.txt`, актуальные результаты `whole_file_result.txt` и `streaming_result.txt`, а также `java_file_result` и `text_result` — результаты предыдущих запусков, оставленные для примера. Возможный большой тестовый файл `large_text.txt` игнорируется Git, чтобы случайно не закоммитить его.
