# WordFrequencyCounter

Считает, сколько раз встречается каждое слово в текстовом файле. Имя файла вводится с клавиатуры.

Слово — последовательность букв и цифр, регистр не учитывается. Результат выводится по алфавиту (`TreeMap`).

**Два варианта подсчёта:**

- **`countWords`** — весь файл загружается в память одной строкой и сразу разбивается на слова.
- **`countWordsStreaming`** — файл читается по символу. Символы копятся во фрагмент, который разбирается и очищается на переводе строки, а если фрагмент длиннее 8192 символов — на ближайшем разделителе, чтобы не разрезать слово. В памяти хранится только текущий фрагмент, поэтому файл может быть больше оперативной памяти.

**Запуск:**

```
javac WordFrequencyCounter.java
java WordFrequencyCounter
```
