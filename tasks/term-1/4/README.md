**Реализация:**
Создан класс `WordFrequencyCounter`, который подсчитывает частоту слов двумя способами:
1. `countWords` — загружает весь файл в память с помощью `Files.readAllLines()`, подходит для небольших файлов.
2. `countWordsStream` — использует `BufferedReader` для построчного чтения, позволяет обрабатывать файлы, размер которых превышает объем доступной оперативной памяти.

**Особенности:**
- Слова приводятся к нижнему регистру, удаляются знаки препинания.
- Результат сортируется по убыванию частоты.
- Запуск показал, что потоковый метод работает быстрее (0.0022 с и 0.0482 с) за счет меньших накладных расходов на выделение памяти под весь список строк.
