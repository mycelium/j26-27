### 4. Java: Word Frequency Counter

Постановка задачи:
- Реализовать подсчет частоты слов в текстовом файле в двух вариантах:
  - Загрузка всего содержимого файла с последующей обработкой
  - Потоковая обработка файла (программа должна обрабатывать файлы большего объема, чем доступная оперативная память)
- Выводить результат работы подсчета

Сохранен скелет, данный в базовом файле.

### Функции.

countWords(Path filePath) -- читает текстовый файл и возвращает Map<String, Integer> с частотой слов. 
Автоматически выбирает способ: для маленьких файлов (< 2% от maxMemory) читает целиком через Files.readString, для больших — потоково через BufferedReader с буфером 8 КБ, поэтому обрабатывает файлы больше доступной памяти.

Лучше использовать полное чтение только на очень маленькие файлы, ограничение в 2 % поставлено только для учета памяти пользователя (так, например, будет работать даже с mawMemory = 3мб).

printFrequencies(Map<String, Integer> frequencies) -- выводит пары "слово: количество" по одной на строку.

main(String[] args) -- точка входа. Создаёт тестовый файл test.txt (если его нет), запускает подсчёт и печатает результат.
