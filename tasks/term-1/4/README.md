## HSAI 26-27 Java course - 1

### 4. Java: Word Frequency Counter

Постановка задачи:

- Реализовать подсчет частоты слов в текстовом файле в двух вариантах:
    - Загрузка всего содержимого файла с последующей обработкой
    - Потоковая обработка файла (программа должна обрабатывать файлы большего объема, чем доступная оперативная память)
- Выводить результат работы подсчета

### Реализация

Класс `WordFrequencyCounter` содержит два метода подсчёта и один метод вывода.

- **`countWords(Path filePath)`** - первый вариант (читает **весь файл целиком** в одну строку через `Files.readString()`), затем разбивает её на слова регулярным выражением `\\W+` и обновляет `Map<String, Integer>`. Использует `merge(word, 1, Integer::sum)` для увеличения счётчика. При ошибке чтения возвращает пустую мапу.

- **`countWords2(Path filePath)`** - второй вариант (потоковый). Открывает файл через `BufferedReader` в блоке `try-with-resources` и читает его **построчно** в цикле `while ((line = reader.readLine()) != null)`. Каждая строка обрабатывается отдельно: приводится к нижнему регистру, разбивается по `\\W+`, слова добавляются в ту же `HashMap`. Увеличение счётчика реализовано через `containsKey` / `put` - без `merge`.

- **`printFrequencies(Map<String, Integer> frequencies)`** - выводит результат: для каждой пары «слово → количество» печатает строку `слово: количество`.

- **`main`** - запускает оба метода на файле `text.txt` и выводит результаты. Файл лежит в корне проекта.
