# Word Frequency Counter

Программа для подсчёта частоты встречаемости слов в текстовом файле. 

Реализованы два  способа обработки данных:
1. **Чтение всего файла в память** – простой и быстрый способ для файлов небольшого размера.
2. **Потоковое чтение (построчное)** – позволяет обрабатывать файлы, размер которых превышает доступный объем оперативной памяти (устойчиво к `OutOfMemoryError`).


- `countWords(Path filePath)` – считывает всё содержимое файла в строку с помощью `Files.readString`, разбивает её на слова и возвращает карту (`Map`) с частотой повторений.
- `countWordsStreaming(Path filePath)` – использует `BufferedReader` для построчного чтения файла. Обрабатывает каждую строку независимо, что минимизирует потребление оперативной памяти.
- `printFrequencies(Map<String, Integer> frequencies)` – принимает карту частот и выводит пары "слово: количество" в консоль, предварительно отсортировав их по алфавиту с помощью `TreeMap`.
- `main(String[] args)` – точка входа. Принимает путь к файлу как аргумент командной строки (по умолчанию использует `input.txt`), запускает оба метода и выводит результаты.
