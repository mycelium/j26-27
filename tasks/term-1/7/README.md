# Лаба 7. Параллельное умножение матриц

Каждый поток считает свой кусок строк. Для сравнения используется обычный `multiply` из первой лабы.

Запуск лабы
```bash
java MatrixMultPar.java 1600
```

В аргументах только размер матриц. Если его не указать, будет 1600. Число потоков берётся из JVM, максимум по одному на строку.

## Замеры

Apple M4 Pro, 12 ядер, OpenJDK 27. Программа делает один прогрев и один замер для каждого варианта. В таблице медиана трёх замеров на матрицах 1600 × 1600.

| Потоки | Время, мс |
| --- | ---: |
| Лаба 1 | 1273,3 |
| 1 | 1247,3 |
| 2 | 740,9 |
| 4 | 332,7 |
| 6 | 220,3 |
| 8 | 208,9 |
| 10 | **186,9** |
| 12 | 187,8 |

## Выбор числа потоков

На моём Mac'e `Runtime.getRuntime().availableProcessors()` возвращает 12. Столько логических процессоров доступно JVM, поэтому для настройки по умолчанию сравнивал варианты до 12 потоков. В этом замере 10 и 12 потоков дали почти одинаковое время, разница меньше 1 мс. При обычном запуске программа берёт 12 потоков.
