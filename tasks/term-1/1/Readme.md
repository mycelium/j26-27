# Оптимизация умножения матриц


В исходном варианте алгоритма умножения матриц используются три вложенных цикла в порядке `i → j → k`.

**Результаты измерений:**
- Время выполнения: приблизительно `1800–2100 мс`.

## 2. Изменение порядка циклов

Порядок циклов изменён с `i → j → k` на `i → k → j`. Результат умножения остаётся прежним, но последовательный доступ к элементам строк улучшает использование кэша процессора.

**Результаты измерений:**
- Время выполнения: приблизительно `180–208 мс`.
- Ускорение: примерно в 10 раз.

## 3. Блочное умножение матриц

Матрицы обрабатываются небольшими блоками. Это позволяет эффективнее использовать кэш процессора. Для поиска подходящего размера блока были проведены измерения.

**Результаты измерений:**

| Размер блока | Время выполнения |
|---:|---:|
| 100 | 204 мс |
| 64 | 163 мс |
| 120 | 143 мс |
| 30 | 216 мс |

Лучший результат среди проверенных вариантов показал блок размером `120 × 120` — приблизительно `143 мс`.
