# Matrix Multiplication

## Оптимизация

В обычном алгоритме внутренний цикл обращается к элементам второй матрицы по столбцам. В Java двумерные массивы — это массивы отдельных строк, поэтому такой доступ плохо кэшируется.

Для оптимизации изменён порядок циклов: внутренний цикл идёт по строке второй матрицы, а не по столбцу. Также используются локальные ссылки на строки и пропуск нулевых элементов. Это улучшает локальность доступа к данным и уменьшает время выполнения.
