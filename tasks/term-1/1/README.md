### 1. Java: Matrix multiplication

`MatrixMult.java` — исходный код.
`result.txt` -- результаты работы программы.

## Постановка задачи:

- реализовать функцию `public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix);`
- Вывести время выполнения для матриц большой размерности
- Оптимизировать время выполнения (описать в README примененные подходы)

## Решение

Для ускорения работы алгоритма была применена оптимизация доступа к памяти через транспонирование второй матрицы.

Двумерные массивы в Java хранятся в памяти построчно. В наивном алгоритме внутренний цикл обращается к элементам `secondMatrix[k][j]`, которые лежат далеко друг от друга. Это вызывает частые промахи кэша.

**Суть оптимизации:**

Перед началом умножения вторая матрица транспонируется. В результате этого алгоритм умножает строку первой матрицы на строку транспонированной второй матрицыk. Элементы в строке лежат в памяти последовательно, что позволяет процессору эффективно загружать их в кэш и обрабатывать блоками.
