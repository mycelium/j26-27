# Умножение матриц

Реализована функция `multiply` с проверкой размеров матриц. В `main` замеряется время умножения
случайных матриц 500×500, 1000×1000 и 2000×2000 для наивной и оптимизированной версии.

Оптимизации:
- порядок циклов i-k-j вместо i-j-k — строки матриц читаются подряд, меньше промахов кэша;
- строки и элемент `a[i][k]` вынесены в локальные переменные;
- нулевые элементы пропускаются;
- умножение блоками 64×64, чтобы часть второй матрицы оставалась в кэше.

Результат для 2000×2000: ~110 с у наивной версии и ~4 с у оптимизированной.
