# Matrix Multiplication

## Оптимизация

В обычном алгоритме внутренний цикл обращается к элементам второй матрицы по столбцам. В Java двумерные массивы представляют собой массивы отдельных строк, поэтому такой доступ менее удобен для кэширования данных процессором.

Для оптимизации вторая матрица предварительно транспонируется. После этого внутренний цикл последовательно читает элементы строк обеих матриц. Это может улучшить локальность доступа к данным и уменьшить время выполнения.

Время оптимизированного алгоритма включает время транспонирования второй матрицы.
