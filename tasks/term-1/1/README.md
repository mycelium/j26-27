# MatrixMult.multiply

В первой версии функции перемножение элементов матриц **C[i][j] += A[i][k] * B[k][j]** происходило в порядке перебора **i -> j -> k**. Таким образом матрица-результат формировалась поэлементно.

Ниже представлены действия, предпринятые для оптимизации вычислений.

## 1. Одномерный массив для вычисления результата

Вычисление результата происходит в **double[] resultMatrixTMP** размером **rows * cols**, а не в **double[][]**.

В **double[][]** каждая строка лежит по отдельному адресу, и разные строки могут находиться в памяти далеко друг от друга. А для одномерного массива выделится один непрерывный участок памяти.
В нем **[i][j]** элемент находится по индексу **i * cols + j**.

Это важно из-за того, что процессор подгружает данные в кэш не по одному числу, а блоками по 64 байта (кэш-линиями), то есть сразу по 8 значений double. Когда элементы лежат подряд, один такой блок содержит несколько нужных для вычислений в данный момент соседних элементов, и следующие обращения берут данные уже из кэша, а не из оперативной памяти.

Вычисленный одномерный массив переносится в итоговый **double[][]** построчно через **System.arraycopy**. Данная операция блочного копирования быстрее поэлементного копирования через циклы. Ее сложность O($N^2$) мала по сравнению с O($N^3$) самого умножения, поэтому накладные расходы, связанные с копированием результата вычислений в двумерный массив, не повлияют на общее время для больших матриц.

## 2. Перестановка циклов **ijk** → **ikj**

```java
for (int i...){ 
    for (int k...){
        for(int j...){
            result[i][j] += a[i][k] * b[k][j];
        }
    }
}

```

Во внутреннем цикле меняется только **j**, поэтому обращение к **b[k]** и **result** идёт вдоль строки без скачков, и в кэш попадает сразу несколько элементов строк матриц. А значение **a[i][k]** при таком порядке лежит в регистре и не перезагружается.

## 3. Вынос инвариантов из внутреннего цикла

Вне цикла по **j** вычисляются:

- **shiftIndex = i * secondMatrix_j** - смещение индекса строки результата
- **rowElement = firstMatrix[i][k]** - скаляр, не меняющийся по **j**
- **rowSecondMatrix = secondMatrix[k]** - ссылка на строку второй матрицы

Из-за этого во внутреннем цикле нет повторного разыменования **secondMatrix[k]** и **firstMatrix[i]**.
