# 1. Java 1

Мой оптимизированный способ перемножения матриц - перестановка с i-j-k в i-k-j порядок. Данная перестановка ускоряет процесс умножения матриц в ~3 раза:

| Способ | Общее время выполнения для 3 раз (ns) | Среднее время выполнения для 1 раза (ns) |
|--------|---------------------------------------|------------------------------------------|
| Классический (i-j-k) | 8695439947 | 2898479982 |
| Перестановка (i-k-j) | 2649562315 | 883187438 |
