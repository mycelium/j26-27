1. Java: Matrix multiplication
- реализовать функцию public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix);
- Вывести время выполнения для матриц большой размерности
- Оптимизировать время выполнения (описать в README примененные подходы)


В Java элементы одной строки массива лежат в памяти подряд. При обращении к элементу процессор загружает в кэш целую кэш-линию (обычно 64 байта, то есть 8 значений double).

В обычном порядке циклов i-j-k программа берёт строку первой матрицы и столбец второй, перемножает их элементы и складывает. Поскольку во второй матрице счёт идёт по столбцам, процессору приходится каждый раз обращаться к медленной оперативной памяти. Поэтому время выполнения можно сократить, если из второй матрицы брать значения не по столбцам, а по строкам.

Для этого был применён порядок i-k-j. Программа берёт один элемент первой матрицы и умножает его на всю строку второй матрицы, добавляя результат в строку итоговой матрицы. Теперь все матрицы читаются по строкам: следующие элементы уже лежат в кэше, и процессор реже обращается к оперативной памяти.
