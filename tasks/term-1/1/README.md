# Matrix multiplication

Программа реализует умножение двух матриц типа `double[][]`.

## Основной метод

```java
public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix)
```

Перед умножением проверяется возможность перемножения матриц. Количество столбцов первой матрицы должно быть равно количеству строк второй матрицы.

Если размеры матриц не подходят, выбрасывается `IllegalArgumentException`.

## Замер времени

Для измерения времени выполнения используется:

```java
System.nanoTime()
```

Время переводится из наносекунд в миллисекунды.

Пример полученных результатов:

- матрицы `1000 x 1000` — около `615 мс`;
- матрицы `2000 x 2000` — около `5470 мс`.

## Оптимизация

Изначально использовался порядок циклов:

```text
i -> j -> k
```

После оптимизации порядок был изменён на:

```text
i -> k -> j
```

C таким порядком программа последовательно обращается к элементам строк второй матрицы.

Лучше использует кэш процессора и уменьшает количество медленных обращений к памяти.

Количество операций не изменяется, поэтому сложность алгоритма остаётся:

```text
O(n^3)
```

Но на больших матрицах время выполнения стало сильно меньше.

Например, для матрицы `1000 x 1000` исходная версия выполнялась примерно за `5844 мс`, а после изменения порядка циклов— примерно за `615 мс`.

## Запуск

Компиляция:

```bash
javac MatrixMult.java
```

Запуск:

```bash
java MatrixMult
```
