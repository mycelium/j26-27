## Использованный метод оптимизации времени

Для оптимизации времени умножения двух матриц обычным алгоритмом с кубической сложностью был применен метод умножения на транспонированную матрицу.

Перед умножением вторая матрица транспонируется. В таком случае умножается уже не строка на столбец, а строка на строку. Этот метод основан на сокращении числа кэш-промахов, которые возникают из-за особенностей хранения массивов в оперативной памяти. В прямом алгоритме первая матрица читается по строкам, а вторая - по столбцам, следовательно, каждое обращение к элементу второй матрицы требует загрузки новой кэш-линии. При умножении на транспонированную матрицу обращение идет последовательно и по строкам для каждой матрицы.

Метод позволил существенно изменить время умножения матриц. Например:
- Для двух матриц 1000x1000: простой алгоритм - 978.8509 мс; с транспонированной матрицей - 449.7563 мс.
- Для двух матриц 2000x2000: простой алгоритм - 58671.8901 мс; с транспонированной матрицей - 5268.7143 мс.

При этом результат умножения и сложность алгоритма не меняется, так как оптимизация основана на технических особенностях вычислений, а не на математическом алгоритме.
