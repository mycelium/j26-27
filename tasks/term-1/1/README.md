# Задание 1. Java: Matrix multiplication

Файл: `MatrixMult.java`.

## Реализация

Реализована функция:

    public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix)

В конце работы программы выводится время выполнения функции на матрицах размерности 512x512 и контрольные значения.

## Оптимизации

- Изменён порядок циклов с классического `i-j-k` на `i-k-j`, внутренний 
    цикл идёт по строке второй матрицы и строке результата, что улучшает 
    локальность данных и работу с кэшем.
- Строки матриц вынесены в локальные переменные `aRow`, `bRow`, `cRow`, 
    что убирает лишние разыменовывания массива в каждой итерации.

## Запуск

    javac MatrixMult.java
    java MatrixMult
