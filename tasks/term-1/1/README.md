Для оптимизации времени выполнения было применено транспонирование второй матрицы.
В памяти двумерный массив хранится по строкам. При поэлементном перемножении матриц secondMatrix[k][j] заставляет итератор перемещаться по строкам, так как цикл k вложен в цикл j. В связи с этим работа кэша процессора ухудшается и перемножение матриц происходит медленнее. При транспонировании второй матрицы, строки поменяются со столбцами местами и при перемножении итератор будет идти по порядку. Данная оптимизация позволила перемножить 2 матрицы размера 1000х1000, заполненные случайными числами от 1 до 100 за 1239.298344 ms, в то время как стандартный алгоритм перемножения занял 2917.841363 ms.
Примечание: для реализации метода необходимо, чтобы вторая матрица была квадратной.
