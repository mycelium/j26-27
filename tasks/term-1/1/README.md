Были реализованы два метода перемножения матриц:
1. `multiply` - классический алгоритм, обход циклов i-j-k.
2. `multiplyOpt` - оптимизированный алгоритм, обход i-k-j с выносом элемента из первой матрицы (firstMatrix[i][k]) в локальную переменную val.

Оптимизация работает быстрее за счет последовательного доступа к памяти. При обходе i-k-j внутренний цикл j читает данные по порядку (слева направо). В классическом методе цикл k прыгает по столбцам второй матрицы, что замедляет работу с памятью.

Замеры производились при перемножении матриц размерностей 1000x2000 и 2000x1000.
* Классический метод: ~17 500 мс.
* Оптимизированный метод: ~1 700 мс.

Время выполнения оптимизированного метода быстрее примерно в 10 раз.
