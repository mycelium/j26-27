Порядок циклов изменён с i-j-k на i-k-j.
В обчной версии внутренний цикл идёт по столбцу второй матрицы — элементы столбца лежат в памяти не подряд, поэтому кэш работает плохо.
После перестановки циклов внутренний цикл идёт по строке и оба массива читаются последовательно, что уменьшает время выполнения.
