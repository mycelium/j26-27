# Применённые подходы к оптимизации

## 1. Перестановка циклов `i - j - k` → `i - k - j`

В Java двумерный массив — это массив ссылок на одномерные массивы-строки, поэтому элементы
одной строки лежат в памяти подряд, а элементы одного столбца — нет.

- В `i - j - k` внутренний цикл идёт по `k` и читает `secondMatrix[k][j]`. На каждой итерации
  происходит переход на другую строку. Доступ по столбцу плохо использует кэш процессора
  (почти каждое обращение — cache miss, т.к. из кэш-линии используется только один элемент).
- В `i - k - j` внутренний цикл идёт по `j` и читает `secondMatrix[k][j]` и `result[i][j]`
  последовательно вдоль строки. Кэш-линия используется полностью,
  а процессор может эффективно делать предвыборку данных.


## 2. Вынесение ссылок на строки из внутренних циклов

Ссылки `firstMatrix[i]`, `result[i]`, `secondMatrix[k]` и значение `firstMatrix[i][k]`
берутся один раз во внешних циклах. Это убирает повторные разыменования
и проверки границ в самом цикле.
