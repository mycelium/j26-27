# Оптимизация

Применена перестановка вложенных циклов: вместо порядка i-j-k используется i-k-j.

Двумерный массив в Java хранится как массив строк, и элементы одной строки лежат в памяти подряд. Процессор подгружает данные в кэш блоками, поэтому чтение подряд идущих элементов быстрее, чем чтение с прыжками по памяти.
Количество операций и результат не меняются, меняется только порядок обращения к памяти.

В исходном варианте (i-j-k) внутренний цикл перебирает k и читает secondMatrix[k][j], то есть на каждой итерации переходит на другую строку второй матрицы. Это вызывает постоянные промахи кэша.

В оптимизированном варианте (i-k-j) внутренний цикл перебирает j при фиксированном k, поэтому secondMatrix[k][j] и result[i][j] читаются и записываются последовательно вдоль строки.
