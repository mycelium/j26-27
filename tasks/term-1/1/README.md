### 1. Java: Matrix multiplication. Постановка задачи.

- реализовать функцию `public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix);`
- Вывести время выполнения для матриц большой размерности
- Оптимизировать время выполнения (описать в README примененные подходы)
  
### Функции
- multiply(firstMatrix, secondMatrix) -- умножение матриц с обходом циклов i-j-k.
- multiplyOptimized(firstMatrix, secondMatrix) -- оптимизированное умножение матриц с обходом i-k-j.
- randomFillMatrix(matr) -- заполнение матрицы случайными числами в диапазоне от 0 до 10.

### Описание оптимизации
Изначально умножение было реализовано по циклу i-j-k (функция multiply). В multiplyOptimized изменён порядок обхода: вместо i-j-k используется i-k-j. 

Когда программа обращается к элементу массива, процессор подгружает в кэш не один элемент, а целый блок соседних адресов. 
Если следующий нужный элемент лежит рядом, то он уже в кэше, и обращение почти бесплатное. 
Если далеко — приходится снова идти в оперативную память, что медленнее.
Матрица в Java хранится построчно.

При обходе i-j-k внутренний цикл идёт по столбцу второй матрицы, и её элементы лежат в памяти не подряд. 
При обходе i-k-j внутренний цикл идёт по строке, поэтому выполнение быстрее.
