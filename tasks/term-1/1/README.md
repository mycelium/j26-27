# Умножение матриц на Java
 
Функция `public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix)` реализована в трёх версиях. Время замеряется через `System.nanoTime()` на матрицах 1000x2000 и 2000x1000 (результат 1000x1000).
 
Запуск любой версии:
 
```bash
javac MatrixMultN.java
java MatrixMultN
```
N = {'', '1', '2'}
 
## Версия 1 (`MatrixMult.java`)
 
**Метод:** базовый. Для каждого элемента результата копируется столбец второй матрицы (`reverseCol`) и считается скалярное произведение со строкой первой матрицы (`getEl`).

Даны: матрица 1000x2000 и 2000x1000:
 
**Время:** `32.3` с
 
## Версия 2 (`MatrixMult2.java`)
 
**Метод:** однократное транспонирование второй матрицы.
 
**Оптимизация:** в версии 1 столбец копировался заново для каждого элемента результата (1 000 000 раз), к тому же столбец читается из разных строк памяти, что плохо для кэша процессора. Здесь вторая матрица транспонируется один раз, после чего скалярное произведение считается между двумя строками, которые читаются подряд. Лишних копирований нет, кэш используется эффективно.

Даны: матрица 1000x2000 и 2000x1000:

**Время:** `3.2` с

Даны: матрица 2000x4000 и 4000x2000:

**Время:** `26.3` с
 
## Версия 3 (`MatrixMult3.java`)
 
**Метод:** порядок циклов i-k-j без транспонирования.
 
**Оптимизация:** внутренний цикл идёт по строке `secondMatrix[k]` и строке результата `ans[i]`, то есть обе читаются подряд, и транспонировать матрицу не нужно. Итерации внутреннего цикла независимы друг от друга (в отличие от цепочки `res += ...` в скалярном произведении), поэтому JIT-компилятор может применить векторизацию, а процессор может выполнять операции одновременно. Ссылки на строки (`ai`, `ci`, `bk`) и значение `aik` вынесены из внутренних циклов.
 
Даны: матрицы 1000x2000 и 2000x1000:

**Время:** `2.9` с

Даны: матрицы 2000x4000 и 4000x2000:

**Время:** `21.0` с
