## Описание
Для умножения матриц я выбрал порядок циклов `i-k-j`. На каждом шаге берётся значение из первой матрицы, затем оно по очереди умножается на элементы нужной строки второй матрицы. Полученные произведения сразу прибавляются к соответствующим ячейкам строки результата.

Такой порядок не сокращает число умножений и сложений: сложность все равно будет O(n^3). Его преимущество в том, что программа чаще обращается к соседним элементам строк. Это может улучшить работу кэша процессора. В проведённых мной замерах реализация с циклами `i-k-j` выполнилась быстрее исходного варианта.
