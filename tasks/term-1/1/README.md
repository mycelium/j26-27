# Matrix Multiplication

Программа на Java для умножения матриц.

Реализованы два алгоритма умножения матриц с использованием трёх циклов: оптимизированный и не оптимизированный.
До оптимизации использовался порядок циклов i-j-k, при котором доступ к элементам второй
матрицы выполняется по столбцу, что снижает эффективность использования кэша;
после оптимизации порядок изменён на i-k-j: строки второй матрицы и результата обрабатываются
последовательно, а firstMatrix[i][k] сохраняется в локальной переменной. Сложность остаётся O(n³).

### Запуск

Для компиляции:

```bash
javac MatrixMult.java
```

Для запуска:

```bash
java MatrixMult
```
