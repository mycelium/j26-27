## Первоначальный вариант
Изначально я написал три последовательно вложенных цикла и прибавлял к элементу строки произведение элементов матриц, которые брал каждый раз по индексу. 

```
for (int i = 0; i < len_col; i++) {
        for (int k = 0; k < len_row; k++) {
            for (int add_ind = 0; add_ind < count_of_addends; add_ind++) {
                res_matrix[i][k] += firstMatrix[i][add_ind] * secondMatrix[add_ind][k];
            }
        }
    }
```
В этом варианте итерация элементов второй матрицы была по элементам столбца. То есть приходилось каждый раз переключаться на другой вложенный список.

## Оптимизация

Чтобы убрать обход по столбцам, я поменял местами два внутренних цикла. Элементы двумерного массива в Java хранятся построчно, поэтому при обходе по строке второй матрицы процессор читает соседние ячейки памяти, и данные лучше попадают в кэш. 

Элемент первой матрицы вынесен в переменную ``a``, так как он не меняется при переборе ``k``.
