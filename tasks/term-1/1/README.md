Реализация:
Написаны две версии умножения матриц в классе `MatrixMult`:
1. `multiply` — прямая реализация (три вложенных цикла i, j, k).
2. `multiplyOptimized` — оптимизированная версия с перестановкой циклов (i, k, j). Внутренний цикл идёт по `j`, что обеспечивает последовательный доступ к памяти второй матрицы.

Замеры времени:
Тестирование проводилось на матрицах размером 500x500. 
- Прямая реализация: 1.130 сек.
- Оптимизированная реализация: 0.246 сек.
- Ускорение: 4.59 раза.

Вывод:
Перестановка циклов позволяет процессору эффективнее использовать кэш, так как данные читаются из памяти последовательно, а не «прыжками» по столбцам. Это значительно ускоряет программу.
