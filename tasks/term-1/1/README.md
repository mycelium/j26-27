# 1. Java: Matrix multiplication

**Файлы:**
- `MatrixMult.java` — исходный код с реализацией алгоритма.
- `Main.java` — код для генерации матриц и замера времени выполнения.

**Постановка задачи:**
1. Реализовать функцию `public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix);`
2. Вывести время выполнения для матриц большой размерности.
3. Оптимизировать время выполнения (описать в README примененные подходы).

## Решение

Для ускорения работы алгоритма была применена оптимизация, связанная с порядком обхода элементов матрицы.

Двумерные массивы в Java хранятся в памяти построчно. В классическом алгоритме используются три вложенных цикла в порядке `i -> j -> k`. При таком порядке во внутреннем цикле происходит обращение к элементам `secondMatrix[k][j]`, которые лежат в памяти далеко друг от друга (с шагом в размер строки). Это вызывает частые промахи кэша процессора.

**Суть оптимизации:**
Порядок циклов был изменен на `i -> k -> j` (снаружи внутрь).
Теперь во внутреннем цикле мы движемся по строке второй матрицы `secondMatrix[k][j]` последовательно. Так как элементы строки лежат в памяти друг за другом, процессор загружает их в кэш блоками, что значительно ускоряет чтение данных.

Дополнительно, элемент `firstMatrix[i][k]` был вынесен в локальную переменную `temp` перед внутренним циклом. Это избавляет от повторного обращения к массиву по индексам на каждой итерации внутреннего цикла.

## Результаты замеров

Замеры проводились на квадратных матрицах размером 500x500 (заполненных случайными числами типа `double`).

- **Базовая реализация (`i -> j -> k`):** ~238 мс
- **Оптимизированная реализация (`i -> k -> j` + локальная переменная):** ~52 мс

Ускорение составило примерно **4.5 раза**.
