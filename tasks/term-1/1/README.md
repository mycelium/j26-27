## 1. Java: Matrix multiplication

Реализована функция `public static double[][] multiply(double[][] firstMatrix, double[][] secondMatrix)`.
Для сравнения добавлен наивный вариант умножения `multiplyNaive`, произведение считается по определению (циклы i-j-k).

Запуск:
```bash
javac MatrixMult.java
java MatrixMult
```

### Применённые оптимизации

1. **Перестановка циклов (i-k-j).** В наивном варианте внутренний цикл читает `secondMatrix[k][j]` из разных строк, это приводит к постоянным промахам кэша. В порядке i-k-j внутренний цикл последовательно проходит по строкам второй матрицы и результата, а элемент `firstMatrix[i][k]` вынесен в локальную переменную. Такой доступ к памяти эффективно использует кэш процессора.
2. **Параллелизация.** Строки результата вычисляются независимо друг от друга, поэтому они распределяются по ядрам процессора через `IntStream.range(0, n).parallel()`. Каждый поток пишет только в свою строку, синхронизация не нужна.
