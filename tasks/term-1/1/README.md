# MatrixMult.multiply

Функция `multiply` реализует умножение двух матриц размера `M×K` и `K×N`
с результатом `M×N` по формуле `C[i][j] = Σ A[i][k] · B[k][j]`. Базовая сложность
алгоритма - `O(N³)`. Ниже описаны приёмы, применённые для ускорения вычислений.

## #1. Блочное умножение

Вычисление разбито на блоки размером `BLOCK_SIZE = 64`. Внешние три цикла
(`si`, `sk`, `sj`) проходят по блокам, внутренние три (`i`, `k`, `j`) - умножают
элементы внутри блока.

Это важно из-за того, что процессор подгружает данные в кэш не по одному числу, а блоками
по 64 байта. Один блок double[64][64] занимает 64 × 64 × 8 = 32 КБ -
примерно размер L1-кэша. Пока блок обрабатывается, все его элементы остаются
в кэше, и процессор не обращается к медленной оперативной памяти за каждым числом.

## #2. Перестановка циклов c i-j-k к i-k-j

Во внутреннем цикле меняется только `j`, поэтому:
- обращение к `secondMatrix[k][j]` идёт **вдоль строки без скачков** - по соседним
  адресам памяти;
- обращение к `thirdMatrix[i][j]` - тоже **вдоль строки**, без скачков;
- значение `firstMatrix[i][k]` при таком порядке **не меняется** во внутреннем
  цикле и вычисляется один раз на каждую пару `(i, k)`.

В наивном порядке `i-j-k` внутренний цикл бегал бы по `k`, и каждое обращение
к `B` прыгало бы по столбцу - через `N × 8` байт. Это даёт по одному промаху
кэша на итерацию. При больших `N` такие прыжки становятся узким местом.
