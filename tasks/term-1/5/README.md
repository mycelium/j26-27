# Анализ отзывов на фильмы

Лабораторная № 5. Stanford CoreNLP определяет тональность английских отзывов и ставит каждому оценку `positive`, `negative` или `neutral`.

## Запуск

Gradle запускается на JDK 24 и собирает приложение под Java 23. Эта команда обработает первые 20 отзывов. Запускайте её из папки лабораторной.

```bash
./gradlew run --args='data/imdb.csv 20'
```

Сначала передайте путь к CSV, затем количество отзывов, если нужен лимит. Без числа программа прочитает весь файл.

В IntelliJ IDEA можно запустить задачу Gradle `app:run` с теми же `--args`.

Распакуйте [датасет IMDB](https://drive.google.com/file/d/15oxF9_ifxKMBs56eUIaziD4nRH3VUV9E/view) в `data/imdb.csv`. Во входном CSV нужен столбец `review`. Если есть столбец `sentiment`, исходная оценка попадёт в результат рядом с оценкой программы.

## Результат

Программа записывает результат в `data/results.csv` поверх предыдущего. В нём исходный текст, метка из датасета (если есть) и оценка CoreNLP. Для отзыва из нескольких предложений программа усредняет оценки с учётом длины предложений.
