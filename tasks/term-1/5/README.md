# Лабораторная работа №5: Sentiment Analysis with CoreNLP

## Описание работы программы
Приложение принимает на вход CSV-файл с отзывами на фильмы (в текущей реализации — `IMDB Dataset.csv`), в котором содержатся текст отзыва и его исходная тональность (`positive` или `negative`). 

Программа читает файл потоково, построчно, корректно склеивая многострочные отзывы. Для анализа текста используется библиотека **Stanford CoreNLP**. 
Текст каждого отзыва очищается от HTML-тегов (`<br />` и др.), после чего разбивается на предложения. Модель CoreNLP оценивает тональность каждого предложения по шкале от `-2` (Very Negative) до `+2` (Very Positive). 

Далее программа агрегирует результат: 
* Если сумма баллов по всем предложениям больше нуля, отзыву присваивается метка `positive`.
* Если сумма баллов меньше нуля — `negative`.
* В остальных случаях — `neutral`.

В консоль выводится прогресс (каждый 50-й отзыв и первые 5 для демонстрации), а в конце работы отображается итоговая точность модели (процент совпадений предсказания с исходной меткой).

## Почему предсказания могут расходиться с оценками в датасете?
Точность модели на датасете IMDB не будет стопроцентной, и вот основные причины этого:

1. **Отсутствие класса `neutral` в датасете**: В исходном датасете есть только положительные и отрицательные отзывы. Если модель CoreNLP решает, что отзыв нейтральный (например, сумма баллов равна нулю), это автоматически засчитывается как ошибка, хотя по смыслу текст может быть действительно нейтральным.
2. **Смешанные эмоции (Mixed Sentiments)**: Пользователи часто пишут длинные отзывы, где хвалят актерскую игру, но сильно ругают сценарий, или наоборот. Модель считает тональность каждого предложения отдельно. Если негативных предложений окажется чуть больше, весь отзыв будет помечен как `negative`, хотя общий посыл автора мог быть положительным.
3. **Сарказм и ирония**: Классические NLP-модели (включая CoreNLP) плохо распознают сарказм. Фраза «Ну конечно, это же *гениальный* фильм...» будет воспринята как положительная, хотя на самом деле она несет негативный смысл.
4. **Контекст и специфические выражения**: Модель анализирует предложения изолированно. Она может не понять специфический сленг, культурные отсылки или сложные речевые обороты, которые в контексте фильма имеют противоположный смысл.
5. **Негатив об упаковке или доставке**: В отзывах люди часто жалуются на качество DVD-диска, проблемы с доставкой или отсутствие субтитров. Для модели это минус (отрицательные слова), хотя сам фильм может быть оценен автором на «отлично».

## Как запустить
1. Убедитесь, что в корне проекта находится файл датасета `IMDB Dataset.csv`.
2. В файле `build.gradle.kts` убедитесь, что выделено достаточно оперативной памяти для JVM (CoreNLP требует много памяти):
   ```kotlin
   tasks.named<JavaExec>("run") {
       maxHeapSize = "4g"
   }
   ```
3. Запустите сборку и выполнение через терминал:
    ```bash
    ./gradlew run
    ```
