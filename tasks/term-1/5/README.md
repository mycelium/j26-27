Приложение принимает путь к CSV-файлу с отзывами, читает его по одной записи и анализирует текст с помощью Stanford CoreNLP. Модель оценивает тональность каждого предложения по шкале от −2 до +2. Если средний балл отзыва не ниже +0,5, приложение присваивает ему метку `positive`, если не выше −0,5 — `negative`, в остальных случаях — `neutral`. Рядом с исходным файлом создаётся отчёт `<имя>-sentiments.csv` с номером отзыва, его текстом, исходной меткой и предсказанием. В консоли отображаются прогресс и итоговая статистика.

Предсказание может расходиться с разметкой, потому что программа учитывает тональность всех предложений, даже если часть из них не выражает мнения о фильме. Например, автор может хотеть показать фильм друзьям, но при этом жаловаться, что нигде не может найти его на DVD. Модель может принять эту жалобу за отрицательный сигнал, а косвенную рекомендацию оставить без положительной оценки. Кроме того, в исходном датасете есть только метки `positive` и `negative`, поэтому любое предсказание `neutral` формально считается расхождением.
