# Лабораторная работа № 5. Анализ тональности отзывов

## Задание

Написать приложение на Java, которое с помощью Stanford CoreNLP определяет
тональность каждого отзыва из [датасета IMDb](https://drive.google.com/file/d/15oxF9_ifxKMBs56eUIaziD4nRH3VUV9E):
`positive`, `negative` или `neutral`.

## Реализация

Приложение читает колонку `review` через Apache Commons CSV и заменяет теги
`<br>` пробелами. Модель Stanford CoreNLP 4.5.9 загружается один раз. Она делит
каждый отзыв на предложения и присваивает каждому из них оценку от 0 до 4:
0–1 — `negative`, 2 — `neutral`, 3–4 — `positive`.

Каждое предложение даёт один голос за свою метку. Отзыв получает метку с
наибольшим числом голосов. При ничьей или отсутствии предложений результат —
`neutral`. Программа выводит номер и предсказанную метку каждого отзыва.
Колонка `sentiment`, если она есть в CSV, используется для проверки точности.

## Запуск

Распакуйте датасет и выполните из папки лабораторной работы с JDK 23 и Gradle 8.14.3:

```sh
gradle :app:run --args='"/путь/к/IMDB Dataset.csv" 20'
```

Второй аргумент ограничивает число отзывов. Если его не указать, приложение
обработает весь файл. Пример вывода:

```text
Review 2: positive (expected: positive)
Review 4: neutral (expected: negative)
```

## Проверка и результаты

Команда `gradle :app:test` проверяет выбор метки по числу голосов, ничью и
отсутствие предложений. Оба теста прошли.

На первых 20 отзывах из IMDb приложение выдало 5 положительных, 8 отрицательных
и 7 нейтральных меток. С разметкой совпали **9 из 20 (45%)**. В IMDb есть только
положительные и отрицательные метки, поэтому `neutral` считается несовпадением.

Для отдельной проверки из 50 000 отзывов случайно выбраны 150 без повторов
(`random.Random(42).sample`): 78 положительных и 72 отрицательных. На одних и
тех же оценках CoreNLP проверены два способа подсчёта голосов. Во втором оценки
0 и 4 получают по два голоса, остальные — по одному.

| Вариант | Совпало с IMDb | Ответов `neutral` | Точность без `neutral` |
| --- | ---: | ---: | ---: |
| Обычное голосование | 98/150 (65,3%) | 32 | 98/118 (83,1%) |
| Двойной вес для 0 и 4 | 99/150 (66,0%) | 31 | 99/119 (83,2%) |

Двойной вес изменил одну метку с `neutral` на правильную `positive`.
В приложении используется обычное голосование: оно совпало с разметкой IMDb
в **98 из 150 случаев (65,3%)**, а двойной вес добавил лишь одно совпадение.
